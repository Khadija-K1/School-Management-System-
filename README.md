# School-Management-System-

A School Management System in Python 🚀

A console-based application built to practice and strengthen 𝗣𝗿𝗼𝗰𝗲𝗱𝘂𝗿𝗮𝗹 𝗣𝗿𝗼𝗴𝗿𝗮𝗺𝗺𝗶𝗻𝗴. The system includes 3 roles:

1. Admin — manages the school
2. Teacher — manages marks
3. Student — views marks

Each role has its own authentication system and permissions.

→👨‍💼 𝗔𝗱𝗺𝗶𝗻 𝗦𝘆𝘀𝘁𝗲𝗺
First comes our admin :D The Admin manages the entire system:

✅ Class management (add/view classes)
✅ Subject assignment
✅ Student Management (CRUD)
✅ Teacher Management (CRUD)

                →👩‍🏫 𝗧𝗲𝗮𝗰𝗵𝗲𝗿 𝗠𝗮𝗻𝗮𝗴𝗲𝗺𝗲𝗻𝘁 𝗦𝘆𝘀𝘁𝗲𝗺 (𝗔𝗱𝗺𝗶𝗻 𝗦𝗶𝗱𝗲)

This part was more complex than student management. Unlike students, teachers can: 
* Teach multiple classes
* Teach multiple subjects in each class

The update system included:
Add new class/subject → Remove subject → Remove an entire class.

→👩‍🏫 𝗧𝗲𝗮𝗰𝗵𝗲𝗿 𝗦𝘆𝘀𝘁𝗲𝗺

Teachers can:
✅ View assigned classes & subjects
✅ Assign & update marks 
✅ View student performance
✅ Change password

→🎓 𝗦𝘁𝘂𝗱𝗲𝗻𝘁 𝗦𝘆𝘀𝘁𝗲𝗺

The student’s job is easy peasy. Students can:
✅ View enrolled class & subjects
✅View marks per subject
✅ See which teacher assigned the marks.

🧠 𝗪𝗵𝗮𝘁 𝗜 𝗽𝗿𝗮𝗰𝘁𝗶𝗰𝗲𝗱:

→ File handling (JSON) for data persistence
→ Nested dictionaries for structured data
→ Functions & modular programming
→ Input Validation systems
→ CRUD Operations
→ Role-based access control
→ Relationship handling between entities (students, teachers, classes, subjects)
→ Authentication System
→ Menu-driven program design

💡 𝗞𝗲𝘆 𝗟𝗲𝗮𝗿𝗻𝗶𝗻𝗴:
One interesting thing I learned was how important 𝗱𝗮𝘁𝗮 𝗰𝗼𝗻𝘀𝗶𝘀𝘁𝗲𝗻𝗰𝘆 is.

For example, when a student changes class, the system automatically updates both student and class records to keep everything synchronized.

This project helped me understand how different parts of a program connect and work together and strengthened my understanding of 𝗣𝗿𝗼𝗰𝗲𝗱𝘂𝗿𝗮𝗹 𝗣𝗿𝗼𝗴𝗿𝗮𝗺𝗺𝗶𝗻𝗴.
